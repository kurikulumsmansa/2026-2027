# Kurikulum SMANSA 2026/2027

Website informasi kurikulum SMANSA tahun pelajaran 2026/2027.

Alamat website: https://kurikulumsmansa.github.io/2026-2027/

## Cara mengubah isi

1. Buka file `index.html` di GitHub, lalu klik ikon pensil (Edit).
2. Ganti tulisan dalam kurung siku seperti `[tanggal]`, `[nama]`, `[email]` dengan data yang benar.
3. Untuk dokumen, ganti `href="#"` dengan link Google Drive.
4. Klik **Commit changes**. Website akan diperbarui otomatis dalam 1–2 menit.

Warna dan tampilan diatur di file `style.css`.
