              Cara Membuat Soal dengan Claude

              Ikuti 8 langkah di bawah. Hasilnya: 100 soal, kisi-kisi, dan kartu soal.

              6. 6
                Kirim Excel ke Claude

              7. 7
                Salin perintah ini, tempel, kirim

                Klik Salin teks, tempel di Claude, kirim. Teksnya tidak perlu dibaca. Claude akan mengisi Excel, kartu soal terisi sendiri. Unduh hasilnya.

                Saya lampirkan file Excel "Kisi-Kisi dan Kartu Soal ASAS-BK". Isi file ini dengan 100 soal yang sudah kamu buat di atas:
1. Sheet Kisi-Kisi: isi identitas Mata Pelajaran (sel C9), Kelas / Fase (sel E9), dan Nama Guru (sel C10).
2. Mulai baris 14 (timpa baris contoh), satu soal per baris sampai baris 113: kolom A nomor, B Tujuan Pembelajaran, C Indikator Soal, D Level Kompetensi (hanya LOTS, MOTS, atau HOTS), E Soal lengkap dengan pilihan A sampai E, F Kunci Soal (satu huruf kapital), G Bentuk Soal (PGS).
3. Jangan mengubah sheet Kartu Soal dan Cek Komposisi, rumus, format, maupun logo. Kartu soal akan terisi otomatis dari sheet Kisi-Kisi.
4. Periksa: 100 soal, LOTS 20, MOTS 50, HOTS 30, semuanya PGS.
Setelah selesai, berikan file Excel yang sudah terisi agar bisa saya unduh.
              8. 8
                Kumpulkan

                Soal ke LMS, Excel kisi-kisi & kartu soal ke Google Form. Paling lambat 14 November.

              Tambahan · Tidak wajib Prompt soal bentuk TKA (PGS, MCMA, PGK) Untuk Bapak/Ibu yang ingin membuat soal 3 jenis seperti TKA. Klik untuk membuka.

              Arahan ASAS-BK tetap 100 soal PGS seperti di atas. Prompt ini hanya contoh bila ingin membuat soal model TKA. Hasilnya satu file Word berisi kisi-kisi, naskah soal, dan kunci, dibuat dalam 3 tahap (40 + 40 + 20 soal). Tahap 2 dan 3 memakai prompt lanjutan di bawah supaya soalnya tidak sama dengan tahap sebelumnya.

              1. 1
                Tahap 1 · Soal nomor 1–40

                Unduh prompt, isi bagian kuning (mapel, kelas, TP per bab, nama, dan tahap 1). Salin dari COPY START sampai COPY END, tempel di claude.ai, lalu kirim. Unduh file Word hasilnya dan simpan.

                Unduh Prompt Tahap 1 (.docx)
              2. ⏳
                Tunggu 5 jam

                Claude membatasi pemakaian. Tunggu 5 jam sebelum lanjut ke tahap berikutnya.

              3. 2
                Tahap 2 · Soal nomor 41–80

                Buka lagi chat yang sama di Claude. Unggah file Word hasil Tahap 1 (klik tanda + atau seret file ke kotak chat). Lalu klik Salin teks di bawah, tempel, kirim. Unduh hasilnya.

                Lanjutkan ke TAHAP 2 dari 3. Saya lampirkan file hasil Tahap 1 (soal nomor 1 sampai 40). Gunakan semua ketentuan dari prompt awal: mata pelajaran, kelas, TP, data tetap, urutan, bentuk dan kaidah soal, serta format keluaran.

Buat 40 soal, nomor 41 sampai 80: LOTS 8 (PGS 6, MCMA 1, PGK 1), MOTS 20 (PGS 12, MCMA 4, PGK 4), HOTS 12 (PGS 6, MCMA 3, PGK 3).

Agar adil dan tidak berulang:
1. Baca dulu seluruh file Tahap 1. Jangan mengulang stimulus, kasus, data, maupun soal yang sudah ada, termasuk soal yang hanya diubah sedikit kata-katanya.
2. Tetap sebarkan ke semua bab dan TP secara proporsional. Utamakan TP yang soalnya masih sedikit di Tahap 1.
3. Lanjutkan penomoran stimulus dari Tahap 1.
4. Jaga sebaran kunci tetap rata: PGS huruf a sampai e sama banyak, kunci MCMA bervariasi, PGK seimbang antara Benar dan Salah.

Keluaran: satu file Word dengan format yang sama seperti Tahap 1 (kisi-kisi, naskah, lampiran), berisi soal nomor 41 sampai 80 saja. Periksa jumlah, urutan, dan kunci.
              4. ⏳
                Tunggu 5 jam lagi

                Setelah Tahap 2 selesai, tunggu 5 jam sebelum Tahap 3.

              5. 3
                Tahap 3 · Soal nomor 81–100

                Buka lagi chat yang sama. Unggah file hasil Tahap 1 dan Tahap 2. Klik Salin teks, tempel, kirim. Unduh hasilnya.

                Lanjutkan ke TAHAP 3 dari 3 (tahap terakhir). Saya lampirkan file hasil Tahap 1 (nomor 1 sampai 40) dan Tahap 2 (nomor 41 sampai 80). Gunakan semua ketentuan dari prompt awal: mata pelajaran, kelas, TP, data tetap, urutan, bentuk dan kaidah soal, serta format keluaran.

Buat 20 soal, nomor 81 sampai 100: LOTS 4 (PGS 2, MCMA 1, PGK 1), MOTS 10 (PGS 6, MCMA 2, PGK 2), HOTS 6 (PGS 4, MCMA 1, PGK 1).

Agar adil dan tidak berulang:
1. Baca dulu seluruh file Tahap 1 dan Tahap 2. Jangan mengulang stimulus, kasus, data, maupun soal yang sudah ada, termasuk soal yang hanya diubah sedikit kata-katanya.
2. Utamakan TP yang soalnya masih paling sedikit di Tahap 1 dan 2, sehingga semua TP terwakili secara adil.
3. Lanjutkan penomoran stimulus dari Tahap 2.
4. Jaga sebaran kunci tetap rata seperti tahap sebelumnya.

Keluaran: satu file Word dengan format yang sama, berisi soal nomor 81 sampai 100 saja. Di bagian akhir, tuliskan rekap total 100 soal dari ketiga tahap: PGS 60, MCMA 20, PGK 20; LOTS 20, MOTS 50, HOTS 30. Periksa jumlah, urutan, dan kunci.
              6. ✓
                Selesai

                Sekarang Bapak/Ibu punya 3 file: nomor 1–40, 41–80, dan 81–100. Periksa bagian bertanda [PERLU VERIFIKASI]. Kalau Claude berhenti di tengah, ketik Lanjutkan.
